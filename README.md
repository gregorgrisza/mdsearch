# Simple search engine for MD documents

## Development

Requires docker.
Checkout sources.

1. Collect documents:
```bash
cd ${PROJECT_ROOT}
rm -fr docs/*
./collect_mds.sh <md_sources_directory>
```
2. Open project in dev container
3. Open Terminal and execute:
```bash
docker compose up --build
```
